## Critérios para entrar aqui

- Dor clara de um nicho específico.
- Entrega em um fluxo curto (formulário + resultado útil).
- Um caminho de distribuição óbvio (comunidade, grupo, indicação).
- Possibilidade de validar cobrança sem grande operação.
